[[kap_Math_V2_1]]
== Math_V2_1: Mathematische Funktionen

Mathematische Standardfunktionen aus dem Modell `Math_V2_1`, die im ilivalidator (iox-ili) ausgewertet werden. `Math_V2_1` ist eine Erweiterung von `Math_V2` (Stand 2023-05-25) um die Funktionen `mod` und `toNumeric`; alle übrigen Funktionen sind in beiden Modellen identisch deklariert. Dokumentiert wird deshalb der vollständige Umfang von `Math_V2_1`.

[cols="2,8"]
|===
|Modell |`Math_V2_1`
|Version |2025-05-05
|Quelle |`DMAV-Validierungsmodell/models/Math_V2_1.ili`; Implementierung `ch.interlis.iox_j.validator.functions.Math`
|===

TIP: Ist ein Argument `UNDEFINED`, wird die Bedingung nicht ausgewertet. Die Beispiele verwenden fiktive Attributnamen.

[[Math_V2_1_atan2]]
=== atan2

[.fn-sig]
.Funktionsname und Signatur (Modell `Math_V2_1`)
[source]
----
FUNCTION atan2(ordinate: NUMERIC; abscissa: NUMERIC): NUMERIC;
----

*Zweck*

Berechnet den Winkel (Bogenmass) des Punktes (abscissa, ordinate) bezüglich der positiven x-Achse.

*Parameter*

[cols="2,6", options="header"]
|===
|Name |Beschreibung
|`ordinate` |Y-Wert (Ordinate) des Punktes.
|`abscissa` |X-Wert (Abszisse) des Punktes.
|===

*Rückgabewert:* `NUMERIC`

*Beispielaufruf*

[source]
----
MANDATORY CONSTRAINT Math_V2_1.atan2(dY, dX) < 1.6;
----

*Skizze und Erläuterung*

.Skizze zu atan2
....
      y
      ▲   • (x=1, y=1)
      │  /
      │ / φ = atan2(1, 1) = 0.7854 rad (45°)
      └───────► x
....

Der Winkel φ wird im Bereich −π … +π geliefert und berücksichtigt im Unterschied zu `atan` den Quadranten.

NOTE: Beide Argumente werden vor dem Aufruf mit `Math.toDegrees` umgerechnet. Da beide Werte mit demselben Faktor skaliert werden, bleibt das Verhältnis und damit der Winkel unverändert.
