[[SO_FunctionsExt_isHttpResource]]
=== isHttpResource

[.fn-sig]
.Funktionsname und Signatur (Modell `SO_FunctionsExt`)
[source]
----
FUNCTION isHttpResource (url: TEXT; prefix: TEXT): BOOLEAN;
----

*Zweck*

Prüft anhand des HTTP-Status-Codes, ob eine HTTP-Ressource vorhanden ist.

*Parameter*

[cols="2,6", options="header"]
|===
|Name |Beschreibung
|`url` |Die URL der zu prüfenden HTTP-Ressource.
|`prefix` |Beliebiger URL-Prefix.
|===

*Rückgabewert:* `BOOLEAN`

*Beispielaufruf*

[source]
----
MANDATORY CONSTRAINT SO_FunctionsExt.isHttpResource(Dokument_URL, "https://geo.so.ch/");
----

*Skizze und Erläuterung*

.Skizze zu isHttpResource
....
url ──► HEAD-Request ──► Status 200…399 ──► TRUE
                │
                └─ fehlgeschlagen ─► GET-Request ──► Status 200…399 ──► TRUE
                                                   └─ sonst ──────────► FALSE
....

Zuerst wird ein HEAD-Request abgesetzt. Schlägt dieser fehl, folgt ein GET-Request. Ein Status-Code ≥ 200 und ≤ 399 ergibt TRUE. Für das Zusammenspiel von `url` und `prefix` gilt die Beschreibung im Modell ("beliebiger URL-Prefix"). Seit 2019-01-27.
